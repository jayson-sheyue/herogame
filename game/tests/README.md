# 升级回归与验收

## 可重复检查

在仓库根目录运行 `python3 game/check.py`。需要 Python 3.11+、Node.js 22+；不安装额外依赖。`--lan-url http://127.0.0.1:8788` 额外使用真实 `serve.py` 服务创建临时房间。测试连接结束后关闭，不写入人物、地图或玩家作品。

- `net.test.cjs`：并发连接去重、握手等待、取消发现请求、旧连接回调隔离、房间身份清理、成功进房、失败后的连接释放。
- `game.test.cjs`：合作地图权限、锁定状态、合作准备入口、单人闯关元数据、必需人物加载、暂停冷却、输入节流、不同端时钟换算、纹理扫描缓存、地图预览尺寸、抽签后的分享地址。
- `shell.test.cjs`：帮助键盘隔离、本地暂停与输入清理、联机手册继续对局、重复失焦、静音偏好、资源失败返回与重新加载、无音频环境偏好、原生按钮键盘隔离。
- `lan-smoke.cjs`：真实 WebSocket 三人房、满房拒绝、准备/输入/状态中继、断线退出、重新加入。

单元回归以轻量场景/DOM 替身检查规则与时序，不等同于渲染引擎、跨机器局域网或所有英雄招式的端到端验收。

## 需要人工体验的流程

1. 选人打开指南，按模式快捷键；关闭后模式不变，再按快捷键可切换。
2. 木桩先直接开战，应提示锁图；锁图后进入战斗。移动、跳跃、普攻、技能后暂停，再恢复；技能冷却不应跳过暂停时间。
3. PVE 换人、切难度，不锁图开战，抽签地图、地址栏和实际场景应一致。结束后 Enter 再战，再 Esc 返回选人。
4. 斗蛐蛐两名 AI 自动对战；闯关单人使用当前英灵与地图，剧情可推进，返回后可重新选择。
5. 合作 / PVP 创建或加入，换人、准备、取消准备、离开再加入。只有主机可以改图；客人的主按钮只切准备，不能误启动单人对局。
6. 声音开关切换后刷新，选择应恢复；全屏再退出；桌面、窄屏与帮助弹窗无关键按钮遮挡。
7. 资源缺失应显示可操作的返回入口；修复资源或换英雄后可继续，不留空白画面。

这些步骤是范围清单；仅在实际记录中标明已执行的项目才算本轮人工通过。

## 性能改动的边界

地图预览纹理上限 1024×576，保留比例；按当前 12 张 `stage.png` 的尺寸计算，原 RGBA 约 194.9 MiB，预览约 20.3 MiB。此为像素存储估算，浏览器总内存还包含图片解码、游戏动作、音频和渲染开销，未以此声称总内存或 FPS 达到某个数字。战斗 HUD 以 30 Hz 更新，战斗仍逐帧运行；静止输入有 30 Hz 心跳，按键边沿与方向变化立即发送。
